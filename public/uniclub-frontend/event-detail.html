Workshop Git & GitHub Actions CI/CD Thực Chiến

Thời gian: 15/10/2026 | 08:00 - 11:30
Địa điểm: Hội trường A2-301
Đơn vị chủ trì: Ban Chuyên môn UniClub
Mục tiêu & Giới thiệu chương trình

Trong các học phần công nghệ phần mềm và đồ án tốt nghiệp, việc cộng tác mã nguồn nhóm thường gặp nhiều trở ngại như xung đột code, không kiểm thử tự động, hoặc triển khai ứng dụng thủ công dễ gặp lỗi. Workshop này mang đến trải nghiệm thực chiến từng bước: từ thiết lập Git Branching, viết Unit Test với JUnit 5, đến cấu hình quy trình CI/CD hoàn chỉnh trên GitHub Actions.

Nội dung chi tiết (Agenda)
08:00 - 08:30 Đón tiếp sinh viên & Điểm danh mã QR tự động Hội viên mở ứng dụng UniClub quét mã QR hiển thị tại màn chiếu hội trường.
08:30 - 09:45 Phần 1: Chuẩn hóa Git Branching Model & Branch Protection Rules Quy tắc nhánh main/develop/feature, cách tạo Pull Request và review chéo giữa các thành viên.
09:45 - 10:45 Phần 2: Xây dựng Pipeline CI/CD tự động bằng GitHub Actions Cấu hình file YAML tự động biên dịch Maven, chạy JUnit Test và đóng gói file WAR triển khai Tomcat.
10:45 - 11:30 Hỏi đáp trực tiếp (Q&A) & Trao chứng nhận tham gia Giải đáp các vướng mắc đồ án và cộng điểm hoạt động phong trào CLB.
Quyền lợi khi tham dự
  • Được cộng +5 điểm rèn luyện học kỳ I năm học 2026-2027.
  • Được cấp mã nguồn mẫu (Starter Template) cấu hình sẵn GitHub Actions.
  • Được cấp giấy chứng nhận tham dự workshop từ Ban Chủ nhiệm CLB.
